# Security Policy

## Supported versions

Security fixes are provided for the latest release. Upgrade to the latest version before reporting an issue that may already be resolved.

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues, discussions, or pull requests. Use [GitHub private vulnerability reporting](https://github.com/w0fv1/gproxyt/security/advisories/new) and include:

- the affected version;
- reproduction steps or a proof of concept;
- the expected security impact;
- any suggested mitigation.

The maintainer will acknowledge a complete report as soon as practical, investigate it privately, and coordinate disclosure after a fix is available. Reports about OpenAI, ChatGPT, Microsoft Store, Windows, or a proxy provider should be sent to the affected vendor instead.
